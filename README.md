# VIIRS-SLSTR-Hotspots

Система для обнаружения и обработки потенциальных очагов возгорания по спутниковым данным VIIRS и Sentinel-3 SLSTR.

## Текущее состояние

- В `viirs_slstr_hotspots/pipline/` находятся заглушки шагов M0–M11; переименование каталога ещё не согласовано.
- Подсистема HS-01 включает модель записи обнаружения, валидатор одной записи и сборщик JSON-отчёта качества.
- Валидатор пока не подключён к шагам M0–M11.
- Запись GeoParquet и полный отчёт качества по пролёту ещё не реализованы.
